# Reviewing and editing an invoice

## The review screen

Open any invoice to see the original file beside the extracted fields. Fields that failed a check are highlighted with a short explanation, such as "Line items add up to 1200.00, but subtotal is 1250.00".

## Editing fields

You can edit any field: vendor, invoice number, date, currency, subtotal, tax, total, and each line item. Save to re-run the checks on your corrected values.

## Approving an invoice

Click Approve once the data is correct. If the invoice still fails a check, for example because the supplier's own invoice has an arithmetic mistake, you must explicitly acknowledge the remaining problem before it can be approved. This prevents approving a bad invoice by accident.

## Invoices that are not invoices

If the file does not look like an invoice or receipt, the app says so instead of showing a form full of "missing" warnings. You can delete it, or fill the fields in by hand if it really is an invoice.

## Receipts

Receipts, including narrow thermal-printer receipts, are read the same way as invoices.
