# Exporting your data

## Formats

Approved invoices can be exported as a CSV file or as an Excel (.xlsx) file. Use the export button at the top of the dashboard.

## What is included

Only approved invoices are exported. Invoices that are still queued, processing, needing review, or failed are left out, so review them first if you want them included.

## Spreadsheet safety

In CSV exports, any cell that starts with =, +, - or @ is neutralised so that a spreadsheet program cannot run it as a formula. This protects you from formula-injection tricks hidden inside an invoice. The text itself is preserved.

## Excel

The Excel export keeps identifiers such as invoice numbers as text, so leading zeros are not lost.

## Getting your data out

Your data stays yours. Export approved invoices at any time and open the file in Excel, Google Sheets or your accounting tool.
